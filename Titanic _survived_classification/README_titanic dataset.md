
 # 🚢 Titanic Survival Prediction

## 📌 Project Overview  
The **Titanic Survival Prediction** project applies **machine learning algorithms** to predict whether a passenger survived the Titanic disaster, based on features such as age, gender, ticket class, and fare.  

This project demonstrates a complete **ML workflow**:  
✔ Data Cleaning  
✔ Exploratory Data Analysis (EDA)  
✔ Feature Engineering  
✔ Handling Missing Values & Imbalance  
✔ Model Building (Logistic Regression) 
✔ Model Evaluation 

## 📑 Dataset

The dataset is sourced from Kaggle’s Titanic competition

Rows: 891

Columns: 12

Target: Survived (0 = No, 1 = Yes)


## 📈 Evaluation

Metrics used: Accuracy,Precision,
Recall,F1-score.

Model gives 76% accurasy on model training.
